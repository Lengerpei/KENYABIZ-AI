# KenyaBiz AI

## Multi-Agent Business Assistant for Kenyan SMEs

KenyaBiz AI is a multi-agent system designed to help
Kenyan startups and SMEs automate customer interactions,
product discovery, quotations, order processing, invoicing,
and payment assistance.

## Architecture

The system uses LangGraph for agent orchestration.

### Agents

1. Supervisor Agent
2. Customer Support Agent
3. Sales & Quotation Agent
4. Order Agent
5. Invoice Agent
6. Payment Agent

### Tools

1. Product Database Tool
2. Quotation Calculator
3. Order Database Tool
4. Invoice Generator
5. Payment Simulator

### Technologies

- Python
- LangGraph
- LangChain
- Groq
- SQLite
- Streamlit
- RAG
- ReportLab
